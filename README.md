# Espaignet Photography

> Site vitrine de **Noé Espaignet** — photographe de rue bordelais, 18 ans, pratiquant la photographie argentique avec une chambre du XIXe siècle fabriquée par **A.Tardy** (Lyon).

🌐 **Site en ligne** : [espaignet-photography.fr](https://espaignet-photography.fr)

---

## À propos du projet

Ce site a été conçu pour présenter et commercialiser des portraits de rue réalisés avec une chambre photographique grand format **13×18 cm** datant du XIXe siècle. Chaque tirage est unique, développé à la main, et livré à domicile.

---

## Structure du site

```
espaignet-photography/
├── index.html        → Page d'accueil
├── galerie.html      → Galerie de portraits (masonry + lightbox)
├── apropos.html      → Histoire, biographie, fiche technique chambre A.Tardy
├── processus.html    → Étapes de création + FAQ
├── tarifs.html       → Les 3 formules (35€ / 45€ / 95€)
└── contact.html      → Formulaire de contact + Instagram
```

---

## Formules proposées

| Formule | Contenu | Prix |
|---|---|---|
| **L'Essentiel** | 1 tirage 13×18 + livraison | 35€ |
| **Le Portrait** | 1 tirage 13×18 + négatif papier + livraison | 45€ |
| **La Relique** | 3 tirages 13×18 + 3 négatifs + livraison | 95€ |

---

## Stack technique

- HTML / CSS / JavaScript vanilla — aucune dépendance
- Zéro framework, zéro build tool
- Hébergé via **GitHub Pages**
- Polices : Playfair Display, IM Fell English, Cormorant Garamond (Google Fonts)

---

## Déploiement

Ce site est statique et ne nécessite aucun serveur. Il tourne entièrement via GitHub Pages.

Pour modifier le site : éditer les fichiers HTML directement et pousser les changements sur la branche `main`.
